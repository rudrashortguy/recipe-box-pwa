# ChefBook PWA

Offline recipe box with ingredient scaling, timer, and shopping list generator.

### Features
- Recipe parser
- Interactive step cooking mode
- Shopping list exporter
- Image caching

### Tech Stack
- **Vite** & **TypeScript**
- **Workbox / Vite PWA Plugin** for offline capabilities
- **IndexedDB & LocalStorage** for persistent state

### Getting Started
```bash
npm install
npm run dev
```
